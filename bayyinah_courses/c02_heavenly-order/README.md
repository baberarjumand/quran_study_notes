## Description

Explore the intricate structure of the Quran, from the organization of individual ayahs to the arrangement of entire surahs. Study how the Quran defies conventional literary norms, offering a unique perspective on divine wisdom. Gain insights into the purpose behind the Quran's organization and its implications for understanding its profound message. Join us on this fascinating exploration of uncovering the heavenly order within the Quran.

## Course File Structure

- Each lesson has its own folder.
- Within each lesson, there are 4 file types: **notes**, **quiz**, **summary**, and **subtitles**.
- Subtitles may sometimes be auto-generated, which can contain inaccurate words for some Arabic letters.
- Subtitle files with timestamps are `.srt` and `.vtt`. The `.txt` file is the same subtitles stitched together with timestamps removed.
