# Divine Speech

**Provider:** BayyinahTV  
**Instructor:** Ustadh Nouman Ali Khan  
**Length:** 10h 44m  
**Lessons:** 13  

**Course link:** [bayyinahtv.com/library/series/16](https://bayyinahtv.com/library/series/16)

## Description

Divine Speech unravels the mysteries of the Quran's unique structure and content. Explore profound questions about repetition, order and storytelling, discovering the divine wisdom behind each aspect. Led by Ustadh Nouman Ali Khan, this course not only deepens your understanding of the Quran but also strengthens your faith in its divine origin.

## Course File Structure

- Each lesson has its own folder.
- Within each lesson, there are 4 file types: **notes**, **quiz**, **summary**, and **subtitles**.
- Subtitles may sometimes be auto-generated, which can contain inaccurate words for some Arabic letters.
- Subtitle files with timestamps are `.srt` and `.vtt`. The `.txt` file is the same subtitles stitched together with timestamps removed.
